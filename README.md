# Звёздный пульт

Android-приложение, которое по домашнему Wi-Fi будит iMac и запускает на нём шорткаты из приложения «Команды»: включение и выключение TorrServe и свои кнопки. Есть виджет на рабочий стол.

## Как это устроено

1. **Пробуждение.** Телефон шлёт Wake-on-LAN (magic packet) на Wi-Fi MAC-адрес iMac, повторяет сигнал и ждёт ответа.
2. **Поиск.** Служба на Mac объявляет себя через Bonjour как `_starremote._tcp`, телефон находит её без ручного ввода IP.
3. **Команды.** Служба на Mac (`mac/agent.sh`, запускается launchd по запросу) выполняет `shortcuts run` и отдаёт статус TorrServe. Доступ по ключу.
4. **Страховка.** При включении Mac сам запланирует шорткат выключения через заданное время, а телефон ставит свой таймер.

## Установка службы на Mac

В Терминале на iMac:

```
curl -fsSL https://raw.githubusercontent.com/jankanat/star-remote/main/mac/install.sh | bash
```

Установщик выведет IP, порт и ключ доступа. Их нужно ввести в приложении: Настройки → Подключение.
Удалить службу: `curl -fsSL https://raw.githubusercontent.com/jankanat/star-remote/main/mac/uninstall.sh | bash`

На Mac должно быть включено «Пробуждать для доступа к сети» (`pmset -g` показывает `womp 1`).

## Сборка APK

Сборка идёт в GitHub Actions при каждом пуше в `main`. Готовый APK лежит во вкладке Actions → последняя сборка → Artifacts → `StarRemote-apk`.

Чтобы обновления ставились поверх старой версии, APK нужно подписывать одним ключом. Ключ хранится в секретах репозитория:
`KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`. Без них APK подписывается временным ключом.

## Секреты

Файл `.env` (см. `.env.example`) лежит только локально и в GitHub не попадает. Ключ доступа к Mac хранится на телефоне в зашифрованном виде и не пишется в журнал.
